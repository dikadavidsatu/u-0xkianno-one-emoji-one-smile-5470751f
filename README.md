One emoji, one smile. This program scores a shortlist of candidate emojis against the judge's own brief — warmth first, then warmth at first glance, universality, being a deliberate pick rather than the default smiley, and being right for a stranger — and writes the winner, 🤗 (a smiling face with open arms, the picture of an offered hug), to `entry.txt`. The winner is validated against the gate before and after writing: exactly one pictographic character, 1–8 characters, not only white space, no variation selector or joiner, and no trailing newline — one emoji and nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
